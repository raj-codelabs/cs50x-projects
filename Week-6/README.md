# Week-6 - Python Programs

A collection of self-contained Python programs covering input/output, loops, text analysis, and DNA profiling.

---

## Features

- `cash/cash.py` — Computes the minimum number of U.S. coins needed to make a given amount of change.
- `hello.py` — Asks the user for a name and prints a personalized greeting.
- `mario-less/mario.py` — Draws a left-aligned half-pyramid of `#` characters of a user-specified height (1-8).
- `mario-more/more.py` — Draws a full two-sided pyramid with a gap in the middle.
- `dna/dna.py` — Identifies a person from a DNA database by matching the longest runs of short-tandem repeats (STRs).
- `readability/readability.py` — Computes the Coleman-Liau reading index of a text.

---

## Requirements

- Python 3.
- CS50 library: `pip install cs50`.

---

## Usage

Run each script directly with Python:

```bash
python cash/cash.py

python dna/dna.py databases/large.csv dna/sequences/1.txt
```

- No compilation is needed.
- Ensure the required input files (such as databases and sequences) are present.
