# Week-8 - Web Development

Two small web programs built with HTML, CSS, and JavaScript: a multi-page homepage and an interactive trivia quiz.

---

## Features

- **Homepage** — A responsive multi-page website with a shared navigation bar, a time-aware greeting, and a contact form with client-side validation.
- **Trivia** — An interactive quiz that provides instant feedback for multiple-choice and free-response questions.

---

## Usage

Open the respective `index.html` files in a browser to run each program.

---
