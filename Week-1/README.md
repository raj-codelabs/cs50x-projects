# Week-1 - C Basics

A set of self-contained C programs that introduce input/output, conditionals, and loops.

---

## Features

- `cash.c` — Computes the minimum number of coins (quarters, dimes, nickels, pennies) needed to make change.
- `credit.c` — Determines the brand and validity of a credit card number using Luhn's algorithm.
- `hello.c` — Prints a simple greeting to demonstrate basic input/output.
- `mario-less.c` — Draws a left-aligned half-pyramid of `#` characters of a user-specified height.
- `mario-more.c` — Draws a centered pyramid of `#` characters using nested loops and formatting.

---

## Requirements

- A C compiler with the CS50 library, or `gcc`.

---

## Usage

Compile each program with `make` and run the resulting executable:

```bash
make cash
./cash
```
