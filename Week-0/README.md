# Dragon Battle - Scratch Game

A Scratch-based action game in which the player controls a warrior who fights a dragon boss using sword attacks. The goal is to defeat the dragon before the player's health reaches zero.

---

## Features

- Player movement using the arrow keys.
- Sword attack system built with Scratch clones.
- Health system for both the player and the dragon.
- Collision detection between attacks and enemies.
- Win and lose conditions.
- Basic animations and sound effects.

---

## How to Play

- Use the **Left Arrow** key to move left.
- Use the **Right Arrow** key to move right.
- Press the **Space Bar** to attack with the sword.
- Hit the dragon multiple times to reduce its health.
- Avoid taking too much damage from the dragon.

The game ends when:

- The dragon's health reaches 0: you win.
- The player's health reaches 0: game over.

---

## How It Works

The game uses variables to track player and dragon health, broadcast messages to communicate between sprites, clones to create sword attacks, and custom blocks to organize the damage logic. A game state variable disables actions once the battle ends.

---

## Notes

- The project is contained in a single file: `Dragon Battle (scratch Game).sb3`.
- The game runs in the Scratch editor.
