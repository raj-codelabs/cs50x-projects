# Sort Data

A collection of sample integer files used to test and benchmark sorting algorithms.

---

## Features

- Datasets in random, reversed, and sorted orders.
- Three dataset sizes: 5,000, 10,000, and 50,000 integers.
- A reference answers file for verifying sorting correctness.

---

## Files

- `answers.txt` — Sorted version of `random50000.txt`, used to verify sorting correctness.
- `random5000.txt` — 5,000 integers in random order.
- `random10000.txt` — 10,000 integers in random order.
- `random50000.txt` — 50,000 integers in random order.
- `reversed5000.txt` — 5,000 integers in descending order.
- `reversed10000.txt` — 10,000 integers in descending order.
- `reversed50000.txt` — 50,000 integers in descending order.
- `sorted5000.txt` — 5,000 integers in ascending order.
- `sorted10000.txt` — 10,000 integers in ascending order.
- `sorted50000.txt` — 50,000 integers in ascending order.

---

## Usage

Feed the files into a sorting algorithm to benchmark performance and verify that the output matches `answers.txt` where applicable.
